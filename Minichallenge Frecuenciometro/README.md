**Minichallenge Frecuenciometro**

Objetivo: El objetivo de esta práctica es diseñar y construir un frecuencímetro utilizando los timers de un microcontrolador. Este dispositivo será capaz de medir la frecuencia de una señal de entrada con precisión (+-1%) y mostrar el resultado en una pantalla.

Materiales:

Microcontrolador
Cristal oscilador (según la especificación del microcontrolador)
Pantalla LCD o display de 7 segmentos
Circuito de acondicionamiento de señal (si es necesario)
Cables y protoboard para conexiones
Descripción de la Práctica:

Configuración del Microcontrolador:

Configurar los pines del microcontrolador: establecer el pin de entrada donde se recibirá la señal cuya frecuencia se desea medir.
Configurar el cristal oscilador externo para asegurar una frecuencia de reloj precisa para los timers.
Visualización de la Frecuencia:

Mostrar la frecuencia medida en una pantalla LCD o en un display de 7 segmentos. La pantalla debe actualizarse periódicamente para reflejar la frecuencia actual de la señal de entrada.
Implementación del Código:

Escribir el código en C o en el lenguaje soportado por el entorno de desarrollo del microcontrolador.
